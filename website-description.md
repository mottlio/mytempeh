 This is a single-page website called MyTempeh.org containing high-level information in Polish and English with the ability to toggle between the two languages on what is tempeh: the fermented soy Indonesian food. It contains information about what it is, how it is made, how to prepare it and how to store it. It contains a few short paragraphs of text, a few photos showing raw tempeh and also tempeh that is already prepared that is part of a finished meal. And then at the bottom, it lists links to sources that users can navigate to find out more.
